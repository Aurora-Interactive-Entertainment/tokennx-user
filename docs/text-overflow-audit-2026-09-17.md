# 文字溢出与响应式适配检查（2026-09-17）

## 修改边界

本轮只修复文字越界、固定容器遮挡及窄屏空间分配，保留导航左右 40px、现有主题配色、卡片尺寸与交互。英文长文案按需适配字号、换行或内部间距；小屏表格复用局部横向滚动。未修改业务数据、模型权限或付款状态。

## 已修复

| 区域 | 原因与修复 |
| --- | --- |
| 顶部轮播胶囊 | 英文 Subscription 使用中文字号且与 Free 角标争用空间；按胶囊断点适配英文文案并预留角标空间，保留按钮尺寸和动画。 |
| 首页优惠与邀请卡 | 优惠标签固定宽度、邀请说明与链接提示强制单行；标签按文字容纳，说明在原区域内换行。 |

| 账单 | 固定窄列中的日期与表头重叠；在原账本滚动容器内保留完整列内容。余额与指标数值补充长数字换行保护。 |

| 企业审计日志 | 英文日期越过窄列；补齐表格原有省略策略，完整时间仍在日志详情中查看。 |

图片生成页面尚未开放：静态修复了模型选择按钮、参考图英文标签及长错误信息的容纳规则。实名提示弹窗的英文长按钮也增加了局部换行保护；当前账号已实名，未通过实际交易去触发该业务分支。

## 浏览器覆盖

实际访问 36 个页面入口，在当前个人账号及已有测试企业中检查，企业检查后恢复个人工作区。主要尺寸为 320、390、897、1440 CSS px，另外检查了 780px 文档导航断点；覆盖英文、中文及深浅主题。

- 公开页面 14 个：首页、模型、排行、智能体、价格、文档、服务状态、关于、联系、快速接入、新闻列表、用户协议、隐私政策、充值协议。
- 个人控制台及共用入口 14 个：快速开始、模型目录、API 密钥、个人用量、费用、订阅、购买、充值、实名认证、个人设置、邀请、企业入驻、对话、视频。
- 企业页面 8 个：角色权限、模型管理、企业设置、企业密钥、分析、成员、用量、审计日志。

对上述页面测量可见文字与容器边界，并对 390/897px 的公开与个人页面补查纵向文字越界。针对轮播胶囊、邀请卡、模型报价、智能体列表、设置、账本、认证步骤、企业模型可见性弹窗核对截图。原本用于表格、代码、多报价和导航的局部滚动不作为页面溢出。

动态内容检查使用当前实际数据；未对所有可能的后台长文案、每个动态详情 ID、登录/支付/外部授权分支作穷举执行。未开放图片功能及未触发弹窗分支以源码和 CSS 检查为准。
