## **特别提示**

本协议由 Token NX 平台运营者（以下简称“平台运营者”或“平台”）与注册、访问或使用 Token NX 服务的用户（以下简称“您”）订立。

Token NX 是模型 API 聚合网关及配套管理平台，不训练基础模型，不发布自有模型权重，也不属于您所选择模型的模型服务提供方。**请您重点阅读服务边界、模型输出、费用结算、服务暂停与终止、免责声明及责任承担等条款。平台将依法以加粗、弹窗、单独确认或其他显著方式提示与您有重大利害关系的条款。**

## **第一条 定义及协议范围**

1. “平台服务”指 Token NX 网站、控制台、API 网关、模型目录、API 密钥管理、调用及用量记录、费用管理、企业工作空间及平台实际开放的其他服务。
2. “模型服务提供方”指其模型通过平台向您提供推理能力的第三方模型公司或其他服务提供者。
3. “输入内容”指您通过平台提交的提示词、参数、文件及其他数据；“模型输出”指模型服务提供方的模型根据输入内容生成或返回的内容。
4. 本协议适用于您访问、注册及使用平台服务的行为。《隐私政策》《服务协议》及充值、订阅、账户注销和主体变更等专项协议，与本协议共同构成双方约定。
5. 专项协议仅在其对应事项范围内优先适用；个人信息处理事项适用《隐私政策》，不得由一般商业条款予以排除或限制。

## **第二条 协议成立及用户资格**

1. 本协议正式发布后，您完成注册、勾选同意本协议或实际使用平台服务的，视为接受本协议。依法需要单独同意或另行确认的事项，不因您接受本协议而免除相应程序。
2. 您应当具有与所实施民事行为相适应的民事行为能力。您代表法人或其他组织使用服务的，应当已经取得充分、有效的授权。
3. 平台不面向未成年人提供注册、充值、订阅或 API 调用服务。未满十八周岁的个人不得注册或以本人名义使用平台服务。平台发现账户实际由未成年人使用时，可以停止相关服务，并依法处理已收集的个人信息和未结费用。
4. 您不得冒用他人身份，不得使用虚假、违法或失效的信息注册账户。

## **第三条 服务内容及变更**

1. 平台按照实际开放的功能、服务页面、订单及本协议提供服务。未正式开放或未在订单中列明的功能，不构成平台的交付义务。
2. 平台可以根据法律法规、监管要求、模型服务提供方变化、网络与基础设施状况、安全风险或合理经营需要调整服务内容。
3. 调整对您已经购买并处于有效期内的服务产生实质不利影响的，平台应当依法提前通知，并根据具体情况提供继续履行、替代方案、按未履行部分退款或其他合法处理方式。
4. 因紧急安全事件、监管措施或模型服务提供方紧急下线而无法提前通知的，平台应当在合理期限内补充说明。

## **第四条 账户及凭证安全**

1. 您应当提供真实、准确、完整的信息并及时更新。依法需要实名认证或企业认证的，您应当按照页面要求完成核验。
2. 您应当妥善保管账户、验证码、API 密钥及其他凭证，不得转让、出租、出借或向未经授权的第三方披露。
3. 通过您的账户或 API 密钥实施的操作，在无相反证据的情况下视为您的行为。因平台安全缺陷、平台违法处理或其他应由平台负责的原因造成的未授权操作，不适用前述推定。
4. 发现凭证泄露、异常调用或其他安全事件时，您应当及时停用相关凭证并通知平台。平台应当在其控制范围内采取冻结、验证、限流、阻断或其他必要措施。

## **第五条 使用规范**

1. 您应当遵守中华人民共和国法律法规、监管规定、强制性国家标准及公序良俗，并保证对输入内容拥有合法权利或已经取得必要授权。
2. 您不得利用平台从事危害国家安全、侵害他人合法权益、诈骗、赌博、暴力、淫秽色情、恶意攻击、传播恶意代码、侵犯个人信息权益或知识产权等违法违规行为。
3. 未经平台书面同意，您不得转售、出租或出借平台账户及 API 密钥，不得绕过计费、限流、权限或安全机制，不得干扰平台正常运行。
4. 您将模型能力用于医疗、法律、金融、生命安全、关键基础设施或其他高风险场景时，应当根据适用法律和实际风险设置专业人员复核、独立安全校验、权限控制和应急处置机制，不得将未经核验的模型输出直接作为最终专业结论或自动执行依据。

## **第六条 模型服务及模型输出**

1. Token NX 仅提供模型 API 的聚合接入和管理服务，不能改变模型的参数、训练数据、内在偏见或固有技术局限。
2. 模型版本、能力范围、内容策略、数据处理规则和服务可用性可能由模型服务提供方决定或受其影响。平台也可以基于合规审查、供应情况、成本、安全或经营安排决定是否接入、展示、暂停或下线特定模型。
3. **平台不替模型服务提供方保证模型输出的真实性、准确性、完整性、及时性、适用性、原创性、不侵权性或可商用性。模型输出不构成医疗、法律、金融、投资或其他专业意见。**
4. 您应当在使用、传播或据以采取行动前独立审核模型输出，并根据适用场景履行内容审核、人工复核和生成合成内容标识等义务。
5. 平台对输入内容采取合规审核措施，不代表平台已经审核、认可或保证模型输出。平台仍应当对其自身依法负有的安全管理、告知和处置义务承担责任。

## **第七条 内容及知识产权**

1. 输入内容的权利归您或原权利人所有。您授权平台在完成模型调用、结算、安全防护、争议处理和履行法定义务所必要的范围内处理输入内容。
2. 平台不因提供聚合接入服务而取得模型输出的所有权。模型输出的权利归属和使用限制，应当结合适用法律及相应模型服务提供方规则确定。
3. 平台网站、控制台、软件、接口文档、标识及其他由平台运营者或相关权利人提供的内容，其知识产权归平台运营者或相关权利人所有。
4. 任何一方不得利用本协议侵犯第三方知识产权、商业秘密、个人信息权益或其他合法权益。

1. 收费项目、价格、计费单位、扣费时点、结算方式及优惠规则，以调用发生时已经生效的计费规则、订单或双方另行签署的书面文件为准。

1. 企业工作空间设企业所有者、企业管理员和企业成员三类系统角色；企业所有者还可以创建自定义角色，作为可命名的权限组合分配给成员。自定义角色不产生企业所有权。
2. 企业所有者为全部企业管理员配置一套共同适用的管理员权限集，并为自定义角色配置其权限范围。企业管理员和自定义角色成员均不得超出被授予的权限范围行使管理权限，不得创建、修改、删除或分配角色；企业成员按照其角色及企业策略使用企业资源。
3. **企业应当及时处理离职、调岗或授权终止人员的访问权限，并对成员、API 密钥和终端系统采取适当的内部安全措施。**
4. 企业工作空间内的成员信息、权限配置、用量和操作记录属于企业治理信息。相关个人信息处理规则适用《隐私政策》。
