# Token NX 隐私政策

**Token NX 隐私政策**

- 版本号：预发布稿 v0.3
- 文本状态：未生效
- 生效日期：以正式发布页面公示为准

## **特别提示**

本政策说明 Token NX 平台运营者作为个人信息处理者处理个人信息的规则。Token NX 是模型 API 聚合网关，不训练基础模型。您选择模型并发起调用时，完成调用所必需的输入内容将被传输至相应模型服务提供方。

**模型服务提供方可能作为独立的个人信息处理者，按照其隐私政策和服务条款处理相关信息。平台将在模型详情页或第三方服务清单中展示模型服务提供方、数据路径及适用规则。涉及敏感个人信息或向其他个人信息处理者提供信息时，平台将依法另行告知并取得单独同意。**

## **第一条 适用范围及定义**

1. 本政策适用于您访问、注册及使用 Token NX 网站、控制台、API 网关和企业工作空间时发生的个人信息处理活动。
2. “交互数据”指您提交的提示词、参数、文件及模型返回内容。
3. “调用元数据”指调用时间、模型、状态、Token 数量、延迟、费用、Request ID 及不包含交互正文的记录。
4. 本政策未规定的术语，适用《中华人民共和国个人信息保护法》及其他相关法律法规的定义。

## **第二条 个人信息的收集及使用**

平台根据实际开放的服务，在实现下列目的所必需的范围内处理个人信息：

| 处理目的 | 可能处理的信息 | 必要性说明 |
|-|-|-|
| 注册、登录及安全验证 | 手机号码、验证码、账户标识、登录时间、IP 地址、设备及浏览器信息 | 创建账户、识别用户并防止未经授权的访问 |
| 实名认证或企业认证 | 依法需要核验的身份信息、企业信息、经办人信息及认证结果 | 履行实名、交易安全或企业资格核验要求 |
| API 调用及计费 | API 密钥标识、调用元数据、账单、订单、支付及开票信息 | 完成调用、计费、对账及交易处理 |
| 企业治理 | 成员身份、角色及权限配置、员工标签、操作记录及企业用量信息 | 实现企业访问控制、费用治理和安全审计 |
| 安全与合规 | 输入审核结果、风险事件、处置记录及依法留存的网络日志 | 防范攻击、违法调用、欺诈及其他安全风险 |
| 客户服务及权利请求 | 咨询、投诉、申诉、证明材料及联系方式 | 回应请求并处理争议 |

平台不会以默认勾选、概括授权或与其他事项捆绑的方式取得法律要求的单独同意。您拒绝提供非必要个人信息，不影响您使用不依赖该信息的其他服务。

## **第三条 交互数据及调用记录**

1. 平台仅在完成模型调用、实时输入审核和传输所必要的时间及范围内处理交互数据。
2. **除您主动启用并另行同意的存储功能，或法律法规、有权机关要求及处理具体安全事件确有必要外，Token NX 不持久化存储提示词及模型输出，也不使用交互数据训练基础模型。**
3. 为计费、对账、安全防护和故障排查，平台可以保存调用元数据。调用元数据不包含提示词、模型输出或能够还原交互正文的内容片段。
4. 模型服务提供方是否留存、审核或使用交互数据，适用其自身规则及平台与其之间的有效约定。平台将在调用前展示相应模型服务提供方及可获得的数据处理说明。
5. 您不应在没有合法处理依据的情况下，通过平台提交他人的敏感个人信息、商业秘密或其他受保护信息。

## **第四条 Cookie 及同类技术**

1. 平台可以使用 Cookie、LocalStorage、SessionStorage 或同类技术维持登录状态、保存必要偏好和保障服务安全。
2. 非必要 Cookie 或同类技术将在依法取得同意后使用，并提供便捷的拒绝或管理方式。
3. 禁用必要 Cookie 可能导致登录、安全验证或部分服务无法正常使用。

## **第五条 委托处理、对外提供及第三方服务**

1. 平台可能委托短信、身份核验、支付、开票、云计算及客户服务提供者处理实现相应功能所必需的信息。平台将与受托人约定处理目的、期限、方式、信息种类及安全义务，并对其处理活动进行监督。
2. 您主动选择模型并发起调用时，平台会将完成该次调用所必需的交互数据和参数提供给相应模型服务提供方。模型名称、模型服务提供方、数据路径和适用规则将在调用前以清晰方式展示。
3. 除取得您的单独同意或法律另有规定外，平台不会向其他个人信息处理者提供您的个人信息，不会公开披露或出售个人信息。
4. 发生合并、分立、解散、被宣告破产或其他需要转移个人信息的情形时，平台将依法告知接收方的名称和联系方式，并要求接收方继续履行本政策及法律规定的义务。接收方变更原处理目的或方式的，应当重新取得您的同意。
5. 平台将通过模型详情页、第三方服务清单或其他便于查阅的页面，持续公布实际接入的模型服务提供方和其他第三方服务。

## **第六条 信息存储期限及地域**

平台在实现处理目的所必要的最短时间内保存个人信息。不同信息的默认保存规则如下：

| 信息类别 | 默认保存期限或确定方式 |
|-|-|
| 账户、联系方式及企业成员关系 | 账户存续期间；注销完成后原则上于三十日内删除或匿名化，法律另有规定的除外 |
| 实名或企业认证信息 | 认证过程所需材料在核验完成后及时删除；认证结果在账户存续期间保存，依法需要继续留存的从其规定 |
| 非交易类调用元数据及输入审核结果 | 自记录产生之日起不超过一百八十日；发生安全事件或争议的，保存至处理完毕后合理期限 |
| 网络运行日志 | 按照适用法律规定保存，依法要求的保存期限不低于六个月 |
| 订单、支付、账单及开票资料 | 自交易完成之日起不少于三年；税务、会计等法律要求更长期限的，从其规定 |
| 企业管理操作记录 | 自记录产生之日起一年；订单或企业书面协议约定更长期限的，按照约定并遵守必要性原则 |
| 客服、投诉及权利请求记录 | 自事项处理完毕之日起一年；存在争议或法定义务的，保存至相关事项处理完毕后合理期限 |

您的个人信息存储在中华人民共和国境内，不向境外提供。保存期限届满后，平台将删除或匿名化处理；技术上难以立即删除的，将停止除存储和采取必要安全保护措施之外的处理。

## **第七条 信息安全**

1. 平台将采取与处理目的、信息类别和风险程度相适应的技术及管理措施，包括访问控制、传输保护、权限管理、安全审计、应急响应和人员管理。
2. 发生或可能发生个人信息泄露、篡改、丢失时，平台将立即采取补救措施，并依法履行通知和报告义务。
3. 您应当妥善保管账户及 API 密钥，避免在不必要的情况下提交敏感个人信息或他人个人信息。

## **第八条 您的个人信息权利**

1. 您依法享有知情、决定、限制或拒绝处理的权利，并有权查阅、复制、更正、补充、删除个人信息，撤回同意及申请注销账户。
2. 平台将在账户设置或正式公布的权利请求渠道中提供申请入口，并在收到申请后十五个工作日内答复；情况复杂需要延长的，将告知延长原因和预计处理期限。
3. 撤回同意不影响撤回前基于同意已经进行的处理。撤回非必要处理的同意，不影响您使用其他不依赖该信息的服务。
4. 平台不持有的交互数据无法由平台提供查阅、复制或删除；平台将对其实际持有的调用元数据、审核记录及其他个人信息依法处理您的请求，并在必要时协助您联系相应模型服务提供方。
5. 平台拒绝您的请求时，将说明主要理由并告知投诉或救济方式。

## **第九条 企业用户及终端用户信息**

1. 企业用户向平台提供成员、联系人或终端用户个人信息前，应当具备合法处理依据并履行必要告知义务。
2. 企业用户与平台对个人信息处理目的和方式另有书面约定的，按照适用法律确定各自角色及责任。企业用户不得通过合同将其依法应承担的义务全部转移给平台。
3. 企业工作空间内的管理员权限集和自定义角色权限均由企业所有者配置。平台将按照服务端权限校验结果控制企业治理信息的访问范围。

## **第十条 未成年人个人信息**

平台不面向未成年人提供服务。平台发现未经合法授权处理未成年人个人信息时，将及时停止相关处理并依法删除。企业用户或开发者不得通过平台提交未取得合法处理依据的未成年人个人信息。

## **第十一条 政策更新及停止运营**

1. 平台更新本政策时，将公示新版本及生效日期。处理目的、处理方式、个人信息种类、保存期限、对外提供发生实质变化的，将依法重新履行告知并取得必要同意。
2. 平台停止运营时，将依法提前通知，并对所持个人信息进行删除、匿名化或依照法定期限封存。
