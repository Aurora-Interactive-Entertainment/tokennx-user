# Token NX 充值协议

**Token NX 充值协议**

- 版本号：预发布稿 v0.3
- 文本状态：未生效
- 生效日期：以正式发布页面公示为准

## **特别提示**

本协议适用于 Token NX 的充值、实付余额、赠送额度、费用抵扣、发票及退款事项。充值功能正式开放后，您在充值前应当核对收款主体、充值账户、金额、支付方式和退款规则。

**实付余额是您实际支付资金形成的预付权益，赠送额度是平台无偿提供的优惠权益，两者分别记账、性质不同。平台不得以赠送额度替代、冲抵或混同您的实付余额。**

**账户存续期间，实付余额不支持主动申请退款，仅可用于抵扣平台服务费用；您申请注销账户时，可以就未消耗的实付余额联系客服申请退回。因计费错误、重复扣款、未经授权扣款、平台未履行服务或停止运营等平台原因，以及法律规定应当退款的情形，不受此限。赠送额度不折现、不退款。**

## **第一条 定义及适用范围**

1. “充值”指您通过平台正式支持的支付方式，向账户支付资金以取得可用于结算平台服务费用的余额。
2. “实付余额”指您实际支付且已经到账的资金对应余额。
3. “赠送额度”指平台在活动、试用或补偿中无偿发放的额度。赠送额度不等同于您实际支付的资金。
4. 充值不构成存款、理财或其他金融产品，账户余额不计付利息，不得用于平台服务费用以外的支付或转账。
5. 订阅及自动续费费用适用相应专项协议。是否可以使用账户余额支付，以订单或付款页面的明确展示为准。

## **第二条 充值条件及收款渠道**

1. 您应当具有与充值行为相适应的民事行为能力，并按照法律法规及平台要求完成必要的实名认证或企业认证。
2. 您应当在支付前核对账户、金额、支付方式和收费规则，并保证资金来源合法。
3. 平台仅通过充值页面、订单或正式书面文件载明的收款主体和支付渠道收款。任何个人或机构通过私下消息提供的账户，未经平台正式确认，不属于平台认可的收款渠道。
4. 平台应当在付款前清晰展示收款主体、应付金额、到账方式、手续费承担及预计到账时间。

## **第三条 充值及到账**

1. 您完成支付且支付渠道确认交易成功后，平台按照实际到账金额增加实付余额。页面显示成功但余额未到账的，您可以提交订单号和支付凭证申请核查。
2. 通过第三方支付服务完成交易的，您同时受该支付服务的规则约束。平台应当对其生成的订单、收款指令和到账记录负责，并在职责范围内协助处理第三方支付异常。
3. 因重复扣款、金额错误或订单状态异常产生争议的，平台应当核对平台订单及支付渠道记录，并依法更正或退款。
4. 账户收到来源不明、错误入账或依法应当冻结的资金时，平台可以采取临时冻结措施，并及时说明原因和核查方式。

## **第四条 余额使用及计费**

1. 余额仅可用于抵扣平台已经开放并明确公示价格的服务费用，不得转让、出租、套现或用于违法交易。
2. 模型调用的计价维度、单价、币种、换算方式、扣费时点及失败请求的计费规则，以调用发生时已经生效的计费规则为准。
3. 平台应当分别展示实付余额、赠送额度和其他权益的收入、扣减、退款及失效记录。
4. 适用多种余额或权益时，扣减顺序以支付前或权益发放时明确展示的规则为准。规则未明确或存在歧义的，不得按照对用户实付资金明显不利的方式解释。
5. 赠送额度的有效期和使用范围应当在发放前明确展示。平台不得在未提前说明的情况下缩短已经发放额度的有效期。
6. 余额不足时，平台可以停止需要付费的服务。余额提醒属于辅助功能，平台未承诺提醒必然送达的，您仍应当自行关注余额变化。

## **第五条 发票**

1. 平台按照实际交易和适用税务规则开具发票，并在开票页面说明发票类型、开票主体、申请条件和处理方式。
2. 赠送额度等未由您实际支付对价的部分，不得重复开具发票。
3. 您应当提供真实、准确的开票信息。因信息错误需要重新开具或红冲的，按照适用税务规则处理。
4. 发生退款时，您应当配合完成必要的发票红冲、退回或其他税务处理。

## **第六条 退款**

1. **账户存续期间，实付余额不支持主动申请退款，仅可用于抵扣平台服务费用。您申请注销账户时，可以就未消耗的实付余额，在扣除已经实际消费的费用后，通过联系客服按照平台公布的流程申请退回；法律法规、支付渠道规则或反洗钱要求另有规定的，从其规定。**
2. 前款不影响以下应当退款的情形：计费错误、重复扣款、未经授权扣款、平台未履行服务或停止运营，以及法律规定应当退款的其他情形；此类退款不以申请注销为前提。已经实际消耗并按照有效计费规则正确结算的服务费用，不属于可退还的未使用余额。
3. 赠送额度原则上不折现、不转让且不单独退款，但平台不得以赠送额度名义扣减或没收实付余额。
4. 经审核可以退款的，原则上退回原支付账户。无法原路退回时，平台可以依法核验申请人身份、资金来源和收款账户。
5. 平台应当在收到完整退款材料后十五个工作日内完成审核或说明不能完成的原因；支付渠道实际到账时间不计入平台审核期限。
6. 平台不得在未明确公示依据、计算方式和申诉渠道的情况下没收实付余额。

## **第七条 注销、服务终止及余额处理**

1. 申请注销账户不导致未使用实付余额自动失效。平台应当在注销流程中提示余额情况和可选择的处理方式。
2. 依法或依约可以退款的余额，可以在注销完成前申请退款，也可以由平台在注销流程中同步办理；用户未单独提出退款申请，不视为放弃实付余额。
3. 因平台停止运营或平台原因无法继续提供付费服务的，平台应当依法处理未使用实付余额和未履行部分。
4. 平台依法需要继续保存交易、退款和开票记录的，注销后仍可以在法定目的和期限内保存。

## **第八条 账户及支付安全**

1. 您应当妥善保管账户、验证码、支付凭证及其他安全信息。发现未经授权的充值或余额消耗时，应当及时通知平台和支付服务提供者。
2. 平台有合理依据认为充值涉及盗刷、洗钱、诈骗、争议代付或司法监管措施时，可以依法暂停相关余额使用，并说明主要原因和材料补充方式。
3. 您不得利用充值、退款或发票功能套现、洗钱、逃税、实施诈骗或从事其他违法活动。
4. 因平台账户安全、计费或记账错误造成损失的，平台应当依法更正并承担相应责任。

## **第九条 协议更新及争议解决**

1. 平台修改涉及余额性质、扣减顺序、退款限制或费用承担的条款时，应当依法采取显著提示；对已经充值的实付余额，不得追溯适用对用户更不利的规则。
2. 本协议适用中华人民共和国法律。双方因本协议产生争议时，应当先行协商；协商不成的，任何一方均可以依法向平台运营者所在地有管辖权的人民法院提起诉讼。
